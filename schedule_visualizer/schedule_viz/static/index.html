Эта вкладка открыта как файл. Для разбора расписания нужен Python-сервер.

Из папки проекта запустите python -m schedule_viz serve --port 18764 --open или откройте приложение, если сервер уже работает.

Укажите день и время или номер пары. Можно добавить тип занятия, аудиторию, преподавателя и чётность недели.
