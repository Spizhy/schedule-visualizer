# Визуализатор расписания

Веб-страница, которая распознаёт скопированный текст расписания и строит из него
интерактивную сетку с цветовой маркировкой предметов.
Только стандартная библиотека Python 3.10+, внешних зависимостей нет.

## Запуск

```bash
python -m schedule_viz serve --port 18764 --open
python -m schedule_viz parse schedule_viz/static/sample.txt   # только разбор -> JSON
python -m unittest discover -s tests -v  # тесты
```

Запускайте команды из папки с `pyproject.toml`. В браузере открывайте
[локальное приложение](http://127.0.0.1:18764/), чтобы работал разбор расписания.

## Что умеет

- Разбирает дни недели (`Пн`, `Понедельник`, `Mon`), время (`09:00–10:30`, `9.00-10.30`),
  номер пары (`2 пара`), тип занятия, аудиторию (`ауд. 301`, `каб. 12`, `онлайн`),
  преподавателя (`Иванов И.И.`, `доц. Иванов И.И.`, `И.И. Иванов`) и чётность недели.
- Занятие может занимать несколько строк; текст из таблиц (с табуляцией) тоже подходит.
- Находит пересечения занятий (с учётом чётности) и подсвечивает их.
- Один и тот же предмет всегда имеет один и тот же цвет; близкие оттенки разводятся.
- Интерфейс: сетка по дням и времени, переключатель «Все / Нечётная / Чётная»,
  легенда-фильтр по предметам, карточка занятия по клику, линия «сейчас», печать,
  светлая и тёмная темы, автосохранение текста в браузере.

## Структура

```
schedule_viz/
  models.py    Lesson, Parity, ParseResult (dataclasses)
  parser.py    parse_schedule(text) -> ParseResult
  colors.py    детерминированные оттенки предметов
  server.py    HTTP-сервер: GET / , POST /api/parse
  __main__.py  CLI (serve / parse)
  static/      index.html, style.css, app.js, sample.txt
tests/         unittest: парсер, цвета, HTTP API
```

## Безопасность и надёжность

- Парсер не бросает исключений на «мусорном» вводе: нераспознанное попадает в `warnings`.
- Ограничение размера запроса (256 КБ), валидация JSON, заголовки CSP / nosniff / X-Frame-Options.
- Статика отдаётся по белому списку (нет path traversal); на клиенте весь текст
  выводится через `textContent`, поэтому внедрение HTML невозможно.

## Свои времена пар

```python
from schedule_viz.parser import parse_schedule
parse_schedule(text, pair_times={1: ("09:00", "10:30"), 2: ("10:40", "12:10")})
```
